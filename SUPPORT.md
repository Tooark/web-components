# Support

Thanks for using Tooark web-components! This page explains where to look first and how to ask for help so
that questions get answered quickly.

## Documentation

- [README](README.md) ([Português](README.pt-BR.md)) — installation per stack, complete examples for Vanilla,
  React, Vue and Angular, the attribute reference of every component, theming and the E2E hooks.
- [Storybook](https://tooark.com/web-components/) — every component live, with its interaction tests.
- Each package ships its own README on npm (`@tooark/web-components`, `@tooark/react`, `@tooark/vue`,
  `@tooark/angular`, `@tooark/chart`, `@tooark/wysiwyg`, `@tooark/code`, `@tooark/motion`, `@tooark/core`,
  `@tooark/tokens`), with installation, configuration, API and examples.
- [CHANGELOG](CHANGELOG.md) — what changed in each version.

## Asking a question

Open an issue: the repository has no Discussions space, so a **blank issue** is the right place for a
question ("how do I…", "is it possible to…"). Include the package and version, the framework you use and a
minimal snippet — a Storybook story name or a StackBlitz link helps a lot.

## Reporting a bug or requesting a feature

Use the issue templates:

- 🐛 [Bug report](https://github.com/Tooark/web-components/issues/new?template=bug_report.yml)
- ✨ [Feature request](https://github.com/Tooark/web-components/issues/new?template=feature_request.yml)

Before filing, search the [existing issues](https://github.com/Tooark/web-components/issues) and update to
the latest published version: only the latest minor receives fixes.

## Security

Do **not** open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md): a private security
advisory on GitHub or `security@tooark.com`.

## What to expect

Tooark web-components is an open-source project maintained by volunteers. Issues are triaged on a
best-effort basis, usually within a few days; there is no SLA and no paid support plan. Pull requests are
welcome — see [CONTRIBUTING.md](CONTRIBUTING.md) for the workflow, and the
[Code of Conduct](CODE_OF_CONDUCT.md) for how we treat each other.
